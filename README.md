# Mani uzdevumi

“Mani uzdevumi” ir vienkārša un atsaucīga uzdevumu pārvaldības lietotne ikdienas darbu sarakstam. Uzdevumus var pievienot, atzīmēt kā izpildītus un dzēst pa vienam. Pieejami filtri, kas ļauj apskatīt visus, aktīvos vai izpildītos uzdevumus. Izvēlēto papildu funkciju — visu izpildīto uzdevumu dzēšanu — var izmantot, nemainot aktīvos uzdevumus.

## Tehnoloģijas

- HTML5
- CSS3
- JavaScript bez bibliotēkām un ietvariem

## Funkcionalitāte

- Uzdevuma pievienošana ar pogu vai Enter; liekās atstarpes tiek noņemtas.
- Uzdevuma izpildes atzīmēšana un atcelšana, redzami izsvītrojot pabeigto tekstu.
- Atsevišķa dzēšanas poga katram uzdevumam.
- Filtri “Visi”, “Aktīvie” un “Izpildītie”, kā arī atlikušo uzdevumu skaitītājs.
- **Papildu funkcija D:** poga “Dzēst visus izpildītos” dzēš pabeigtos uzdevumus, saglabājot aktīvos.
- Uzdevuma pievienošana atsevišķā dialogā ar termiņa un prioritātes izvēli.
- Prioritātes “Augsta”, “Vidēja” un “Zema” tiek attēlotas ar atšķirīgām pasteļkrāsām un teksta apzīmējumiem.
- A–Z kārtošana, statistikas panelis un responsīvs, gaišs lietotnes noformējums.

## Palaišana

Atveriet `mi-pd1-uzdevumi/index.html` tieši pārlūkā Google Chrome vai Mozilla Firefox. Serveris, interneta savienojums un papildu programmas nav nepieciešamas.

## Datu glabāšana

Uzdevumi tiek saglabāti pārlūka `localStorage` ar atslēgu `pd1-uzdevumi`. Dati paliek pieejami tajā pašā pārlūkā un faila izcelsmē arī pēc lapas pārlādes; citā pārlūkā vai citā faila atrašanās vietā var būt atsevišķs datu kopums.
